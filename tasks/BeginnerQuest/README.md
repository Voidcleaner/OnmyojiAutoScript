# BeginnerQuest（试验性新手主线任务）

放在 OAS 的 Script 设置菜单中，默认关闭。可以单独运行 `Script("账号配置").run("BeginnerQuest")`，或启用对应任务调度。请从已经登录的庭院或剧情场景开始；本任务不替代账号验证。

## 已实现并实测的流程

- 庭院/剧情场景的 NPC 三点对话图标（含右边缘被裁切的图标）。
- 对话中的跳过、探查眼睛、怪物问号、剧情战斗入口。
- 识别自动战斗状态等待结算、点击屏幕继续、领取奖励与升级功能提示。
- 第一个 CrossOver 实例从4级推进到7级；完成“屋前的调查”和凤凰林后续剧情，解锁神乐。

另支持右上角 `>│` 动画跳过符号的几何检测，已通过合成图测试，并在当前剧情实测完成动画跳过与确认。

规则采用 `rules.json` 的模板＋区域＋阈值和 OCR 按钮白名单。只对已识别的对象操作；不会把顶部滚动聊天中的关键词当作任务按钮。

## 屏幕外 NPC 搜索

参考困难探索的背景拖动与画面变化比较：未发现交互目标、已确认剧情场景 HUD 且场景中没有对话/菜单文字时，等待3秒后按住背景向左拖动查找。每次移动后重新识别 NPC、探查和战斗图标；目标优先于继续搜索。连续两次背景无明显位移时反向，背景动画持续变化时也会预留反向搜索预算，再遇边界或达到 `max_search_swipes` 后保存现场并停止。未知界面不拖动。

默认 `search_npc=true`、每轮最多8次拖动，搜索也计入任务动作和总时长上限。拖动路径在探索背景安全区域小幅变化；点击中心默认±2像素（可设0关闭），动作后等待0.9—1.5秒。这些变化用于界面容差和动画等待，不能保证避免游戏账号处罚。当前 HUD 模板针对已实测的新手剧情场景，其他场景需要补充准确的 `search_scene` 规则。

## 借用与队伍：仍待实际界面校准

遇到借用提示会记录借用流程，并尝试点击明确的“前往借用/借用式神/借用”，按 `preferred_support` 优先选择待宵姑获鸟（SP鸟）；之后优先 `fire_provider`（默认座敷童子）。

当前测试账号尚未出现可验证的借用编队界面。因此**不能宣称已实现可靠的借用上阵或三人队自动编排**。当场景需要拖动卡牌，或没有匹配的借用角色、打火角色已上阵标记时，任务会停止等待校准，不会用“点过卡牌”冒充上阵成功。

`require_verified_team` 默认开启。`support_on_field` 和 `fire_on_field` 规则是预留的上阵检查点；需要针对实际编队界面加入准确模板，当前发行不提供未经验证的默认模板。可在手工配置好队伍后，从不涉及借用引导的剧情继续测试。

## 边界与停止条件

- 默认每次最多80次动作、600秒、10次战斗入口/准备动作；均可配置。
- 未识别画面等待30秒后保存到 `log/beginner_quest/<配置名>/unrecognized.png` 并退出。
- 同一位置同一种动作连续无进展时退出；已识别资源不足、账号登录或战败提示时退出。
- 运行上限只是本轮结束，不代表整条新手主线通关。
- 使用本任务自己的动作/时长上限，避免通用双按钮循环保护误伤连续的“NPC对话—跳过”。
- 不主动购买体力、抽卡、升级、销毁物品。个性化推荐弹窗选择关闭推荐。

## 配置

`beginner_quest.quest_options` 提供 `max_actions`、`max_seconds`、`idle_seconds`、`max_battles`、`borrow_support`、`preferred_support`、`fire_provider`、`require_verified_team`、`search_npc`、`max_search_swipes`、`click_jitter`、`dry_run`。
`dry_run` 只识别一个可用动作，不发送点击。

测试：项目根目录执行 `python -m unittest discover -s tests -p test_beginner_quest.py`。

战斗准备后会记录等待结算状态，重启可恢复；仅点击已识别的结算按钮，不把战斗特效当作 NPC。跳过确认弹窗也支持跨进程恢复。

角色介绍页采用上下两个固定装饰边框共同识别，可关闭尚未单独录入的角色介绍；亮光必须结合具体界面和交互标记判断，不将普通发光场景装饰作为点击目标。

## 现有模块复用与40级路线

详见 [任务路线、来源及验证边界](../../docs/newbie-route.md)。`planner.py` 可把实际任务要求转换为 `Orochi`、`Exploration`、`ExperienceYoukai`、`Tako` 的短批次调用；它与剧情识别配合，不把社区攻略当作完成凭据。组队任务须有队友连续停留3–5秒，超时不单人开战；战败会停止该批次，先评估阵容与御魂。40级目标仍在实测推进中，不能宣称已有全程无人值守通关能力。
