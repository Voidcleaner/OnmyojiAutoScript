# 新手到40级：资料与 OAS 模块复用

目标账号为第一个实例；第二个仅保留登录页。以游戏中的当前任务、角色等级、锁定状态、战斗结果为准。社区攻略用于补充前置条件，不能把旧攻略的层数、解锁条件当成游戏现状。

## 资料核对（2026-11-02）

- [新手公式化开荒指南，2026-01-20](https://www.gamersky.com/handbook/202601/2078587.shtml)：提供剧情与章节交替、主持经验妖怪/石距、借用式神的路线参考；不照搬其中购买体力、付费、拜师及社交操作。
- GitHub 检索：`缘初手札`、`阴阳师 新手` 未找到可直接执行的完整顺序脚本。[chien97z/onmyoji](https://github.com/chien97z/onmyoji) 是一般资料，[d1321225602/YYS](https://github.com/d1321225602/YYS) 仅有简短 README；[dsh-onmyoji-guide](https://github.com/Free-swallow1/dsh-onmyoji-guide) 是社区资料检索助手且标注 AI 生成，不能据此认定具体新手步骤已验证。未安装或运行这些外部项目。
- [OAS](https://github.com/runhey/OnmyojiAutoScript) 已有可复用任务与导航/战斗/领奖组件。

## 调度与完成验证

| 条件 | 执行 | 验证 |
| --- | --- | --- |
| 新手任务/手札有免费奖励 | 新手界面适配；任务、奖励页分别领取 | 奖励弹窗消失，领取标记改变 |
| 当前主线可推进 | BeginnerQuest 的 NPC、探查、跳过 | 场景/任务文本改变 |
| 主线等级不足 | Exploration 短批次 | 重新读取主角等级，不把式神等级当主角等级 |
| 御魂任务 | Orochi 单人模式，每批1场 | 战斗胜利后重新读新手任务；只从“御魂·X层”提取层数 |
| 觉醒任务 | 新手适配入口，复用战斗组件 | 解锁目标层后通关并回看任务 |
| 主角≥15且经验副本可用 | ExperienceYoukai 创建公开房间 | 有队友连续停留随机3–5秒后才开；人数变化重置计时 |
| 主角≥15且石距可用 | Tako 创建公开房间 | 同上，不单人开局 |
| 战败 | 首次失败即停止该批次 | 记录目标及当前阵容版本；查攻略、评估式神/御魂，先做其他可行目标 |
| 完成展示/结算挡住页面 | 复用 GameUi 的已识别关闭图标与领奖逻辑 | 页面确实切换后再调度 |
| 主角达到40级 | 停止升级消耗 | 以主角等级界面确认 |

`tasks/BeginnerQuest/planner.py` 负责把界面事实转换为短批次的现有模块调用。`run_existing` 复用同一个 Device，并在调用结束后恢复临时配置。子模块结束不自动等于新手任务完成，返回值要求重新核对游戏任务。

## 边界

- 不同画面的准备按钮可能置灰或位置变化：等待可用；按钮持续存在就不能认定已开战。
- 角色获得展示的新粉色关闭图标已加入通用未知页面恢复；不用 Esc 盲退。
- 连续无进展保存诊断并停止盲点；不能把动画等待误报为完成。
- 未验证的借用编队仍需单独校准。当前账号已保存的队伍不等于脚本已实现所有式神自动编队。
